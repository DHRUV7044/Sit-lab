# Semiconductor Technology Lab Synchronizer

This repository is used for syncing TCAD process simulation files from the Semiconductor Integration Technology (SIT) laboratory workstations to a local laptop for academic coursework.

## Academic Contents
- **LAB1 (STI)**: Coventor SEMulator3D process flow scripts (`.vproc`), photolithography layout masks (`.cat`), and materials library database (`.vmpd`) for modeling Shallow Trench Isolation (STI) processes.
- **lab2 (CMOS)**: Coventor SEMulator3D mask layouts for planar CMOS integration (NMOS/PMOS well and junction formations).
